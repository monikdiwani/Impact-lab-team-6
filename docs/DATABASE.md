# Database: `outputs/follow_the_rupee.db`

_Generated by `python -m pipeline.db` — do not edit by hand._

One SQLite file holds the reference data, every cleaned pipeline output and the Claude-written texts, with primary and foreign keys enforced at build time. The app should read from here, not from the parquet/CSV files.

```python
from pipeline import db
df = db.query("SELECT * FROM v_complaint_trail WHERE complaint_id = ?", ["BMC25-000005"])
con = db.connect()          # read-only sqlite3 connection
```

**Kept in step automatically:** every M1 / M2 / M3 run that writes `outputs/` rebuilds this database (`pipeline/db/sync.py`); runs into other folders (tests, backtest) never touch it. Full run: `python -m pipeline` (add `--no-llm` for a free run). Manual rebuild: `python -m pipeline.db`; check freshness: `python -m pipeline.db --check` (exits 1 if an input changed since the build).

Size 7.4 MB · 28 tables · 6 views · timestamps are ISO text `YYYY-MM-DD HH:MM:SS` · all data synthetic.

## Example queries

**Trace one complaint to the money**
```sql
SELECT * FROM v_complaint_trail WHERE complaint_id = 'BMC25-000005'
```

**Where did each ward's money go?**
```sql
SELECT ward_code, ward_name, budget_inr, billed_inr, flagged_inr, planned_repair_inr FROM v_ward_money ORDER BY flagged_inr DESC
```

**Biggest over-bills**
```sql
SELECT work_order_id, contractor_id, billed_inr, expected_inr, amount_at_risk_inr, evidence FROM audit_flags WHERE flag_type = 'OVERBILL' ORDER BY amount_at_risk_inr DESC LIMIT 10
```

**Money billed on roads still under warranty**
```sql
SELECT ward_code, COUNT(*) AS jobs, SUM(cost_inr) AS billed_inr FROM v_work_orders WHERE under_dlp = 'Y' GROUP BY ward_code ORDER BY billed_inr DESC
```

**Next rupee for one ward**
```sql
SELECT rank, road_name, action, recommended_method, est_cost_inr, reason FROM v_next_rupee WHERE ward_code = 'F/S' ORDER BY rank LIMIT 10
```

**All complaints about one issue**
```sql
SELECT complaint_id, channel, language, description FROM complaints WHERE issue_id = (SELECT issue_id FROM complaints WHERE complaint_id = 'BMC25-000005')
```
